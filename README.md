# Sales & Financial Dashboard

## Project Overview

This project presents an interactive Sales & Financial Dashboard created using Microsoft Power BI.

The dashboard helps analyse sales performance using KPIs, charts and interactive slicers.

## Objectives

- Analyse overall sales performance
- Compare sales by product category
- Compare sales by region
- Analyse sales trends over time
- Provide interactive filtering for business analysis

## KPIs

- Total Sales
- Average Sales
- Total Quantity
- Total Transactions

## Visualizations

- Sales by Product Category
- Sales by Region
- Sales Trend Over Time

## Interactive Filters

- Sales Channel
- Product Category
- Region

## Tools Used

- Microsoft Power BI
- Microsoft Excel/CSV
- GitHub

## Conclusion

The dashboard provides an interactive view of sales performance and helps stakeholders understand sales trends, regional performance and product-category performance for better data-driven decision-making.
